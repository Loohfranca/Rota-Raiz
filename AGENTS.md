# Instruções para agentes — Rota Raiz

Este arquivo vale **somente neste repositório** (Loohfranca/Rota-Raiz). Não cria regras globais e não deve ser copiado para outros projetos.

## Skill local de interface e guias de viagem

Para tarefas de criação ou revisão de UI, UX, responsividade, acessibilidade, design system, mapas, guias de praias, rotas de acesso e passeios:

1. **Ler e aplicar integralmente** .agents/skills/rota-raiz-uiux/SKILL.md.
2. Ler docs/ROTA_RAIZ_UX_SYSTEM.md e os componentes/dados afetados.
3. Separar fatos de transporte, maré, distâncias e preços de sugestões puramente visuais.
4. Nunca inventar caminhos, tarifas, horários, fontes ou validações de testes.
5. Preservar os fluxos existentes de React, Vite, Tailwind, Supabase/local, Leaflet, PWA/offline e painel administrativo.
6. Trabalhar preferencialmente em branch e PR; **não fazer merge/deploy automaticamente**.
7. Reportar arquivos, evidências, testes executados e pendências.

Esta skill **não** é instrução para redesenhar o aplicativo inteiro nem autorização para modificar o backend, dados ou publicação fora da tarefa solicitada.

Se o ambiente de agente não carregar skills automaticamente, abrir o arquivo SKILL.md manualmente antes de trabalhar no frontend ou no conteúdo dos destinos.
